# TaskFlow: Сервис контроля и учёта задач

Компактный и стабильный инструмент трекинга задач, созданный на Python с применением легковесного фреймворка Flask и встроенной реляционной базы данных SQLite.

Решение выполнено в ходе практического учебного цикла и наглядно иллюстрирует фундаментальные механизмы серверной разработки: сквозную поддержку CRUD-операций, атомарность транзакций, корректную обработку подключений через конструкцию `try/except/finally` с откатом изменений (`rollback`), фильтрацию SQL-инъекций за счёт параметризации запросов, а также внедрение паттерна Post/Redirect/Get (PRG).

---

## Ключевой функционал

* **Базовые операции CRUD**: создание задач, отображение актуального реестра, изменение текущего состояния (`new` $\leftrightarrow$ `done`), а также безвозвратное удаление записей.
* **Защищённость от инъекций**: предотвращение атак класса SQLi путём передачи аргументов через позиционные маркеры (`?`) и подготовленные инструкции.
* **Контроль соединений и транзакционная целостность**: обязательное закрытие дескрипторов БД в секции `finally: conn.close()`, сохранение транзакций (`commit`) и своевременный `rollback` при исключениях, что исключает блокировку файла базы (`database is locked`).
* **Защита от повторной отправки (PRG)**: исключение появления дубликатов при перезагрузке вкладки в браузере (по нажатию `F5`).
* **Интерактивное отображение через Jinja2**: графическое выделение завершённых пунктов (зачёркнутый текст, маркеры состояния) и диалоговое подтверждение перед удалением (`confirm`).
* **Гибкость взаимодействия**: наличие как терминального режима работы (`crud_console.py`), так и полноценного веб-варианта (`app.py`).

---

## Применяемый стек

* **Основной язык:** Python 3.10+
* **Серверный каркас:** Flask
* **Хранилище данных:** SQLite (стандартная библиотека `sqlite3`)
* **Генерация страниц:** Jinja2
* **Клиентская часть:** HTML5, CSS3

## Архитектура файлов

```text
task_manager/
├── app.db              # Локальный файл БД (генерируется автоматически)
├── init_db.py          # Первичная настройка базы и развёртывание таблиц (DDL)
├── check_db.py         # Диагностика целостности и состава сущностей БД
├── crud_console.py     # CLI-модуль для работы через терминал
├── app.py              # Точка входа веб-сервиса (роутинг и бизнес-логика)
└── templates/
    └── index.html      # HTML-разметка с Jinja-синтаксисом

```
